# Drive-mode lab results, 2026-11-18

Board v7, DRV8316T with OCP/SR (pin 35) **floating**. Motor: 12N14P drone
outrunner (7 pole pairs). VIN 9 V. Firmware: `test_08_drive_lab`, driven by
`firmware/tools/lab.py`. The full console log is
[`2026-11-18_drive_lab.log`](2026-11-18_drive_lab.log).

All feedback comes from the DRV8316 current-sense outputs SOA/SOB/SOC only:
there is no encoder, Hall sensor or phase-voltage sense.

## 1. Static duty table (stalled motor, 300 ms each)

| A / B / C duty | iA | iB | iC | samples with current |
|---|---|---|---|---|
| 10 / 0 / 0 | +3.21 A | −1.63 A | −1.52 A | 99 % |
| 12 / 0 / 6 | +3.07 A | −3.05 A | +0.03 A | 99 % |
| 12 / 2 / 6 | +0.17 A | −0.17 A | 0 | 49 % |
| 26 / 14 / 20 | 0 | 0 | 0 | 0 % |
| 56 / 44 / 50 | 0 | 0 | 0 | 0 % |
| 55 / 45 / 50 | 0 | 0 | 0 | 0 % |

This reproduces the bring-up table: current flows only while one phase is
held at 0 % (low side on, no edges). KCL holds on the SOx readings
(3.21 ≈ 1.63 + 1.52).

## 2. Open-loop commutation (40 % amplitude target, 2 A limit, 15 s ramp)

| Mode | Result | Notes |
|---|---|---|
| 6-step (trapezoidal) | runs, reached 180 Hz el. at the 15 s mark | duty 8 → 20 % with speed (back-EMF tracking); current flowing 100 % up to 60 Hz, ~60 % above |
| Sine PWM | **fails**: 0.01 A at 12 % amplitude, interlock trip | all three phases switching |
| SVPWM | **fails**: 0.01 A, interlock trip | same |
| DPWM (bottom-clamped) | runs, reached 180 Hz el. | 100 % flow below 50 Hz; 41–50 % flow above (sector dropouts) |

Feedback quality: KCL residual (ia + ib + ic, samples where all three are
valid) 0.02–0.05 A RMS. The three CSAs agree to about 1 %.

## 3. Motor parameters from SOx (`rl`)

| Parameter | Value | Method |
|---|---|---|
| R (phase) | 0.138 Ω | integral current loop at θ = 0, 1 A and 2 A, ΔV/ΔI |
| L (phase) | ~11 µH (10.0 at 1 kHz, 12.6 at 2 kHz) | 0.25 V sine injection, lock-in on id |
| λ (flux linkage) | 0.0008–0.0010 Wb | back-EMF in I/f, 13–43 Hz |

λ check: at 200 Hz the 6-step run needed ~24 % of 9 V; √3·ω·λ ≈ 2 V agrees.

## 4. Closed-loop current control on SOx only (I/f)

dq current loop at 400 Hz bandwidth (Kp 0.028 V/A, Ki 346 V/(A·s)), 1.5 A on
an open-loop angle, DPWM modulation.

- 0–43 Hz: id = 1.5 ± 0.1 A, iq ≈ 0, per-phase RMS 1.06–1.07 A (= 1.5/√2:
  sinusoidal currents), 100 % flow, KCL residual 0.02 A.
- 44–59 Hz: current dropouts 4–36 %; the rotor lost sync near 50 Hz
  (λ estimate collapsed to 0.0002 = no back-EMF).
- First version: nFAULT at 17–19 Hz every time. The fault trace showed that a
  dropout let the current PI wind up to ~8 V (93 % duty); when conduction
  returned the current spiked past the DRV8316 OCP. Fixed with a voltage
  bound from the motor model (2·R·ilim + 1.5·ω·(λ + L·ilim) + 0.3 V) and an
  integrator hold while |I| < 30 % of the reference. Peak sample dropped from
  8.5 A to 3.4 A; no faults since.

## 5. Sensorless FOC

Ortega non-linear flux observer + PLL, I/f start, handover at 35 Hz, speed loop.

- **Observer accuracy:** after the fixes below, the PLL read 30.9 Hz at
  30.8 Hz and 34.8 Hz at 35.0 Hz during I/f.
- **Closed loop:** handover worked; the motor ran sensorless for about 2 s from
  35 to 44 Hz (id −1 A, iq ≈ 1 A), then the dropout rate rose to 33–58 % and
  lock was lost. A second attempt with id −1.5 A dropped out at handover.

Findings that made the observer work, from an offline replay of a recorded
35 Hz trace:

| Observer voltage model | Estimated speed (true 35 Hz) | Angle wobble |
|---|---|---|
| written duty × Vbus | 34.2 Hz | 10° |
| + floating-phase reconstruction | 33.5 Hz | 9° |
| − dead-time loss (expected physics) | 14.0 Hz | 133° |
| R +30 % / R −30 % | 13.3 / 34.7 Hz | — |
| λ +20 % / λ −20 % | 16.5 / 34.8 Hz | — |

1. **No dead-time voltage loss on this board.** The phase voltage follows the
   written duty; subtracting the 1 µs dead time breaks the observer. Likely
   ASR (active synchronous rectification, pin 35 floating) conducting through
   the dead time.
2. **Dead-time compensation still helps conduction:** with it off, I/f
   dropouts at 27–35 Hz rose from 0 % to 28–40 %. Keep it on, and feed the
   observer the written duties (which include it).
3. **The observer fails high, not low:** overestimating R or λ breaks it;
   underestimating by 20–30 % is fine.
4. **Phases float near their current zero crossing** (current stuck at 0 for
   25–35°): the DRV8316 turns the half-bridge off at low current.
5. **Low current stops conduction**, so an unloaded motor at id = 0 stalls the
   bridge. Sensorless mode holds id = −1 A to keep |I| ≥ 1 A.

## Conclusions

- With pin 35 floating, only drives that hold a low side on work: 6-step and
  DPWM. Sine and SVPWM pass no current.
- Closed-loop current control from SOA/SOB/SOC alone works (I/f, 0–43 Hz).
- Sensorless FOC works in principle (observer locked, closed loop ran
  35 → 44 Hz) but is not reliable: the DRV8316's ASR/AAR causes current
  dropouts above ~40 Hz and at low current.
- **Next step: tie DRV8316 pin 35 to GND** (ASR/AAR off), power-cycle, rerun
  `raw`, `sine`, `svpwm`, `if` and `sl` with `focmod svpwm`.
